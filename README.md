📝 Project Overview
This project is Practical 1 of the SWID program. It demonstrates basic Python concepts through a fun "Market Day Quest" scenario - shopping in a Cameroonian market.

It covers all 20 tasks from variables to a final Boss Receipt challenge.

🎯 Concepts Covered

**Task 1-4: Variables & Data Types**
- Creating variables (`str`, `int`, `float`, `bool`)
- Checking types with `type()`
- Case sensitivity and variable swapping

**Task 5-8: f-Strings & Formatting**
- f-string interpolation
- Formatting decimals `:.2f`
- Formatting thousands with commas `:,`

**Task 9-14: Operators**
- Arithmetic for market total & change
- Floor division `//` and modulo `%` for sharing oranges
- Percentage discount calculation
- Augmented assignment `+=`, `-=`, `*=`

**Task 15-19: String Operations**
- Concatenation with `+`
- Repetition with `*`
- `str()` conversion and `.lower()` for email generation

**Task 20: Boss Challenge - Market Receipt**
A complete market receipt with:
- Subtotal calculation
- 10% discount
- Change calculation
- Formatted output using `* 20`, `- 20`, and `.center(20)`
